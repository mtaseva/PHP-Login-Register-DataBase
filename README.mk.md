# 🔐 PHP Систем за најава и регистрација

Едноставен систем за корисничка автентикација направен со PHP и MySQL. Овозможува регистрација на корисници, најава и пристап до заштитена страница по успешна најава.

## 📌 Функционалности

- Регистрација на корисници со валидација
- Безбеден систем за најавување
- Сесија за контрола на пристап
- Страници за успех и продолжување

## 🛠️ Користени технологии

- **Backend:** PHP
- **База на податоци:** MySQL
- **Frontend:** HTML, основен CSS

## 🚀 Почеток со користење

### Потребно

- PHP 7.x или понова верзија
- MySQL сервер
- Веб сервер (на пр. Apache преку XAMPP)

### Инсталација

1. Преземете го или клонирајте го овој проект.
2. Увезете ја базата на податоци (доколку е вклучена).
3. Конфигурирајте ги поставките за поврзување со базата во PHP фајловите.
4. Стартувајте го проектот преку локален сервер (XAMPP, WAMP).
