# 🔐 PHP Login and Registration System

A simple user authentication system built with PHP and MySQL. It allows users to register, log in, and be redirected to a protected page after successful authentication.

## 📌 Features

- User registration with form validation
- Secure login system
- Session-based access control
- Success and continuation pages after login

## 🛠️ Technologies Used

- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML, basic CSS

## 🚀 Getting Started

### Prerequisites

- PHP 7.x or above
- MySQL server
- A web server (e.g., Apache via XAMPP)

### Installation Steps

1. Clone or download this repository.
2. Import the SQL schema (if provided) into your MySQL server.
3. Update database connection settings in the PHP files (if needed).
4. Run the project via a local server like XAMPP or WAMP.
